# swot-reservoir-wse

**swot-reservoir-wse** is a Python package for generating reservoir-specific Water Surface Elevation (WSE) time series from Surface Water and Ocean Topography (SWOT) observations using user-supplied dam coordinates, an observation period, and a selected SWOT observation source.

The current release supports:

- **SWOT Level-2 Lake Single Pass (LakeSP) Observation Vector Product, Version D**
- **SWOT Level-2 High Rate Pixel Cloud (PIXC) Product, Version D**
