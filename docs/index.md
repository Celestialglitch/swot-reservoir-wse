# swot-reservoir-wse

**swot-reservoir-wse** is a source configurable Python package that generates reservoir-specific Water Surface Elevation (WSE) time series from Surface Water and Ocean Topography (SWOT) observations using user-supplied dam coordinates, an observation period, and a selected SWOT observation source.

The current release supports the following SWOT Science products:

- **SWOT Level-2 Lake Single Pass Vector Data Product, Version D**
- **SWOT Level-2 Water Mask Pixel Cloud Data Product, Version D**
